# Problem

NovelAgent 需要一个固定、可审计、可迭代的故事质量评测体系。单纯让 LLM judge 给章节打分无法稳定衡量长篇小说 agent 的核心能力，因为高分文本可能仍然破坏人物设定、世界规则、时间线或伏笔状态。

## Observations

- 长篇小说创作是状态ful任务：每章都改变人物、线索和读者预期。
- 当前 NovelAgent 已有结构化状态，但评测仍主要是单元测试和浅层连续性检查。
- 外部 benchmark 提示：长上下文理解、长文本生成、agent 任务和 LLM judge 都各有可借鉴部分，但没有一个直接覆盖“长篇故事创作 agent”。

## Gap

现有评测缺少一个统一 schema，把故事状态、创作动作、预期状态变化、硬约束检查和主观质量 judge 组合起来。
